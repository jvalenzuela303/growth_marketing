The Growth Engine es una plataforma SaaS de embudos inteligentes con IA (quiz funnels + automatización + WhatsApp IA) orientada al mercado LATAM, con foco inicial en Chile.

**Presupuesto MVP:** $600.000 - $1.000.000 CLP mensuales (~$630-$1.050 USD/mes al cambio de $950 CLP/USD)

**Stack tecnológico previsto:** GCP (Cloud Run, Cloud SQL, BigQuery, Cloud Storage), OpenAI GPT-4o, Claude Sonnet via Anthropic API, Vertex AI, WhatsApp Business API (Twilio o directo Meta), SendGrid, n8n

**Competidores directos:** ScoreApp (quiz funnels), HubSpot (CRM/marketing), GoHighLevel (agencias), Vambe AI (WhatsApp IA LATAM)

**Diferenciador clave identificado:** Combinación nativa de quiz funnels + IA conversacional (WhatsApp) + automatización + analytics en español para LATAM — ningún competidor tiene los 4 pilares integrados natively para este mercado.

**Why:** El mercado LATAM carece de una solución all-in-one en español que combine quiz funnels inteligentes con IA conversacional WhatsApp nativa. ScoreApp no tiene WhatsApp. HubSpot es caro y genérico. GoHighLevel está en inglés. Vambe solo hace WhatsApp.

**How to apply:** Al analizar features o pricing, siempre enmarcar la propuesta de valor desde estos 4 pilares integrados. El precio debe ser accesible vs HubSpot/GoHighLevel pero premium vs soluciones puntuales como Vambe.

**Análisis inicial completado:** 2026-05-08 — análisis competitivo completo, framework KPIs, costos GCP, roadmap MVP 4 fases, riesgos técnicos, mercado LATAM (TAM/SAM/SOM).
